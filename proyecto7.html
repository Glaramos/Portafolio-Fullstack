Descripción

Portfolio web desarrollado utilizando React, Vite, JavaScript, HTML y CSS. El objetivo del proyecto fue diseñar y desarrollar una aplicación moderna para presentar mi perfil profesional como QA Tester Manual, destacando proyectos, habilidades técnicas y experiencia en pruebas de software. Se implementó una interfaz responsive adaptable a diferentes dispositivos, navegación intuitiva, componentes reutilizables y una estructura optimizada para ofrecer una experiencia de usuario clara y profesional. El proyecto fue desplegado mediante GitHub Pages, permitiendo su acceso público desde cualquier dispositivo con conexión a Internet.
